# AIMirror

A smart mirror project that combines AI capabilities with a physical mirror interface. This project includes the software, hardware enclosure designs, and 3D printing files needed to build your own AI-powered mirror.

## Overview

AIMirror is designed to run on a Raspberry Pi Zero, providing an intelligent mirror experience. The system includes a client-server architecture with a configuration GUI for easy setup and customization.

## Project Structure

- **Software**: Python-based client application for Raspberry Pi Zero
- **Hardware**: 3D printable enclosure designs (STEP files and GCODE)
- **3D Models**: Mirror of Erised frame design files for larger format printing

## Files

- `AIMirror-AIMirror.zip` - Complete source code and project files
- `Print_Files/` - Contains all 3D printing files:
  - Enclosure designs (top and bottom) in STEP format
  - GCODE files ready for 3D printing
  - Mirror of Erised frame components (split for larger prints)
- `Armin_Tavassoli_Peter_Teresi_AIMirror_Representation.mov` - Project presentation video
- `AIMirror - Final Project Report.docx` - Detailed project documentation

## Hardware Requirements

- Raspberry Pi Zero
- Display (compatible with your mirror setup)
- 3D printed enclosure (files provided)
- Mirror frame (optional - Mirror of Erised design included)

## Software Setup

1. Extract `AIMirror-AIMirror.zip`
2. Follow the installation instructions in the project documentation
3. Configure using the provided GUI tool

## 3D Printing

The enclosure files are provided in both STEP format (for CAD editing) and GCODE format (ready to print). The Mirror of Erised frame has been split into multiple parts for printing on larger bed printers like the CR10 SMART Pro and Ender 3 S1.
